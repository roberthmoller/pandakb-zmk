## App companion (OLED + Keymap Wizard)

macOS menu bar app + firmware hooks for the right OLED (play/pause + volume, battery, link). It also hosts **ZmkWiz** via **Open Keymap Wizard**.

- Companion: [companion/README.md](companion/README.md)
- Wizard UI: [companion/zmkwiz/README.md](companion/zmkwiz/README.md)
- HID protocol: [modules/app-layer/PROTOCOL.md](modules/app-layer/PROTOCOL.md)

Left OLED stays on `nice_oled` (layer name included). Right OLED shows media status.
