# pandakb-app-layer

ZMK module for the PandaKB macOS companion:

- Raw HID commands on the central half (`layer_to`, `set_badge`)
- Global-locality `&badge` behavior so the peripheral OLED can show a game badge
- `game_badge` shield: custom 128x32 status screen with a large badge wordmark

See [PROTOCOL.md](PROTOCOL.md).
